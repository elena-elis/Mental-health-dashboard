Mental Health Dashboard — Power BI 🎨
О проекте
Дашборд раскрывает непростую связь между академической нагрузкой и эмоциональным состоянием студентов. 
За сухими метриками — реальные истории: как средний балл (CGPA) переплетается с уровнем тревожности, а семейный статус — с риском депрессивных эпизодов. 
Цель визуализации — сделать невидимую нагрузку видимой и дать университетам инструменты для точечной поддержки.

📊 Что внутри
Анализ построен на пересечении трёх ключевых состояний: тревожности, депрессии и панических атак.
Особенность данных — в их «пересекаемости»: один студент может одновременно попадать в несколько категорий. 
Это не ошибка, а отражение клинической реальности: ментальные состояния редко приходят поодиночке.

🔍 Главные инсайты

Масштаб проблемы: из 101 респондента признаки тревожности есть у 34 человек, депрессии — у 35. Почти каждый третий студент сталкивается с этими состояниями.
Критическая группа: у 10 студентов одновременно зафиксированы тревожность, депрессия и панические атаки.
Контекст данных: вероятно, данные реальные (основаны на самоотчётах), но локация и контекст исследования не указаны — выводы стоит трактовать как предварительные.

🌐 Источник данных

🛠 Стек технологий

Power BI Desktop, DAX, Power Query

📥 Как запустить

Скачайте файл с расширением .pbix.
Откройте его в Power BI Desktop.
Используйте фильтры, чтобы «провалиться» в детали и увидеть, как меняются распределения в разных подгруппах.
